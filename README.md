## 📖 Deskripsi Proyek

**Manajemen Daftar Mata Kuliah** merupakan program sederhana berbasis Python yang dirancang untuk mengelola daftar mata kuliah secara interaktif melalui terminal atau command prompt.

Program ini memungkinkan pengguna untuk melihat daftar mata kuliah, menambahkan mata kuliah baru, serta menghapus mata kuliah yang sudah tidak diperlukan.

Proyek ini dibuat sebagai bentuk penerapan konsep dasar pemrograman Python, khususnya dalam penggunaan struktur data List, perulangan While, percabangan If-Else, dan manipulasi elemen dalam List.

## 🎯 Tujuan Program

- Memahami penggunaan List sebagai struktur data untuk menyimpan kumpulan mata kuliah.
- Menerapkan perulangan While untuk menampilkan data secara berulang.
- Menggunakan percabangan If-Else untuk memvalidasi masukan pengguna.
- Memahami proses penambahan dan penghapusan elemen pada List.
- Melatih kemampuan membuat program interaktif menggunakan Python.

## ⚙️ Fitur Program

Program ini memiliki beberapa fitur utama:

1. **Menampilkan Daftar Mata Kuliah**  
   Menampilkan seluruh mata kuliah yang tersimpan beserta nomor urutnya.

2. **Menghitung Jumlah Mata Kuliah**  
   Menampilkan total mata kuliah menggunakan fungsi `len()`.

3. **Menambahkan Mata Kuliah**  
   Pengguna dapat memasukkan nama mata kuliah baru. Program menggunakan `append()` untuk menambahkan data ke dalam List.

4. **Validasi Input**  
   Program memeriksa apakah nama mata kuliah yang dimasukkan kosong menggunakan percabangan If-Else.

5. **Menghapus Mata Kuliah**  
   Pengguna dapat menghapus mata kuliah berdasarkan nama yang dimasukkan menggunakan `remove()`.

6. **Menampilkan Daftar Terbaru dan Daftar Akhir**  
   Program menampilkan perubahan daftar mata kuliah setelah proses penambahan dan penghapusan dilakukan.

## 🛠️ Konsep Python yang Digunakan

| Konsep | Fungsi |
|---|---|
| List | Menyimpan daftar mata kuliah |
| `while` | Melakukan perulangan untuk menampilkan data |
| `if-else` | Memeriksa kondisi dan memvalidasi input |
| `input()` | Menerima masukan dari pengguna |
| `append()` | Menambahkan elemen ke dalam List |
| `remove()` | Menghapus elemen dari List |
| `len()` | Menghitung jumlah elemen |
| `strip()` | Menghilangkan spasi di awal dan akhir input |
| `in` | Memeriksa keberadaan mata kuliah dalam List |

2. Download atau clone repository ini.
3. Buka folder proyek menggunakan Visual Studio Code atau terminal.
